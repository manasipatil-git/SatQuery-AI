# data/
`demo/` holds **synthetic** satellite-style scenes generated by `make_demo.py` (3 scenes + a 2023/2026 change pair; files named `change_*` are used only by COMPARE > LOAD DEMO PAIR). They are for demonstrating the workflow, not for evaluating accuracy. Put real exports in any folder and upload them through the app; to list a real image in the sidebar demo picker, copy it into `demo/`.
